Lucy runs on your Mac.

Download Lucy, unzip, open the app, and add Lucy Bridge from the Chrome Web Store when you want Lucy to read webpages. Lucy ships as a universal Mac app for macOS 12+ with Apple Silicon MLX support and Intel Mac local GGUF models through llama.cpp. No cloud account, no subscription, and no browser content leaves your machine.

Stay private on more Macs

Lucy runs locally with MLX on Apple Silicon and local GGUF models through llama.cpp on Intel Macs running macOS 12 or newer. Browser content is handled through localhost.

Smoother installation

Download

Click the direct Lucy ZIP download. The install page also includes a copyable Terminal command for one-step setup.

Open Lucy

Move Lucy wherever you like, then right-click and open if macOS Gatekeeper asks for confirmation. On Intel Macs, use the install guide to enable the local GGUF model backend.

Add browser reading

Install Lucy Bridge from the Chrome Web Store, start the local bridge server, then click the extension icon on any page.

If you only want the desktop app, you can skip the Chrome Bridge until you need webpage reading.

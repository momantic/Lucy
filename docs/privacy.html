Privacy Policy for Lucy Bridge

Lucy Bridge is a Chrome extension that captures the currently active browser tab content when the user clicks the extension icon.

Data Collection

We do not collect, store, or sell personal data. The extension only accesses webpage content temporarily after the user clicks the extension icon, then sends that content to the local Lucy desktop application for processing.

Data Usage

All data captured from webpages is used locally and is not transmitted to any third-party servers. The extension communicates with the Lucy desktop bridge on http://127.0.0.1:8765.

Permissions

The extension uses Chrome's activeTab permission to access only the active tab after the user clicks the extension icon. It uses scripting to read page text on that active tab and localhost access to send the selected page content to Lucy running on the user's Mac.

Third Parties

No data is sold, shared, or transferred to third parties.

Contact

For questions, open an issue on the GitHub repository.
